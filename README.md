# NE555 LED Blinker PCB Design

## Project Overview

This project demonstrates the schematic design and PCB layout of an LED blinker circuit based on the NE555 timer IC, configured as an astable multivibrator.

## Tools Used

* KiCad 10.0
* KiCad Schematic Editor
* KiCad PCB Editor
* KiCad Gerber Viewer

## Project Features

* NE555 astable multivibrator circuit
* Through-hole component layout
* PCB track routing
* PCB board outline using the Edge.Cuts layer
* Gerber fabrication file generation
* Drill file generation

## Project Structure

* `Schematic/` — Circuit schematic
* `PCB/` — KiCad PCB and project files
* `Gerber/` — Gerber layers and drill file
* `Images/` — Project screenshots

## Fabrication Outputs

The `Gerber/` directory contains copper, solder mask, silkscreen and board-outline files, along with the drill file required for PCB fabrication.

## Learning Outcomes

* Understanding the NE555 astable multivibrator
* Schematic capture and PCB layout using KiCad
* Through-hole component placement and track routing
* Preparing Gerber and drill outputs

## Project Status

PCB layout and fabrication-file generation completed. Physical PCB fabrication and testing are not yet confirmed.
